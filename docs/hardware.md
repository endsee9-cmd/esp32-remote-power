# 硬件:接线、供电、固定与校准

## 材料

| 件 | 规格 | 备注 |
|---|---|---|
| 主控 | ESP32-C5-DevKitC,16 MB Flash | 板载 USB 转串口;两个 USB-C 口用途不同,见下文 |
| 舵机 | SG90 **连续旋转**款 | 给 1500 µs 停,大于转一个方向,小于转另一个方向。不是 0–180° 位置款 |
| 电源 | 5 V / ≥1 A 独立供电 | 不要只从板子的 5V 引脚取电 |
| 支架 | 3D 打印 / 亚克力 / 现成舵机支架 | 让舵机臂正好压在电源键上 |
| 固定 | 双面胶、扎带、泡棉 | 泡棉用来吸收行程误差 |

## 接线

| SG90 线 | 接到 |
|---|---|
| 棕 / 黑(GND) | 电源 GND **与 C5 的 GND 相连** |
| 红(VCC) | 独立 5 V |
| 橙 / 黄(信号) | **GPIO24** |

```
  5V 电源 ──┬── SG90 VCC
            └── SG90 GND ──┬── C5 GND        ← 必须共地
                           │
  ESP32-C5 GPIO24 ──────────┴─ SG90 信号
```

### 为什么舵机要单独供电

舵机启动瞬间的浪涌电流能到几百 mA 甚至更高。从板载 5V 取电,电压会被拉下去,C5 会 brownout 复位,
现象是「舵机一动,板子重启、日志从头开始」。看到这个现象先查供电,别怀疑代码。

电源和 C5 的地必须连在一起,否则 PWM 信号没有参考电平,舵机会乱抖。

可选:在舵机电源两端并一个 100–470 µF 电解电容,能明显减少动作时的电压跌落。

### 两个 USB-C 口

DevKitC 上通常一个口是 USB-Serial(走板载 CP210x/CH34x),另一个是芯片原生 USB。
**烧录和看串口日志要用带串口芯片的那个口。** 插错口的表现是设备管理器里没有新串口、
或者 `idf.py` 报找不到设备。

串口名以系统实际枚举为准:Windows 是 `COM5` 这种(不一定是几号,插不同 USB 口都会变),
Linux 是 `/dev/ttyACM0` 或 `/dev/ttyUSB0`。

## 固定结构

目标是让舵机臂**垂直**压在电源键上,行程够用又不把键帽顶死。

1. 先把舵机固定在笔记本旁边,舵机臂悬空,别碰键盘。
2. 上电,用串口 `p` 让它往「下压」方向转,确认转向是朝键盘的;不是就换安装方向
   (或把两根线对调思路不适用,连续旋转款靠脉宽换向,不用改接线)。
3. 用 `a 10` / `a -10` 微调起点,让舵机臂的静止位置离键帽留 2–4 mm 间隙。
4. 装到键帽上方,臂端贴一小块泡棉或硅胶,增大接触面积、减少对键帽的磨损。
5. 检查线束:舵机转动时线不能绷紧,也不能卷进臂的行程里。

**别让舵机臂顶着键帽硬顶。** 连续旋转舵机没有力矩反馈,顶住了它会持续输出力矩、持续发热,
几分钟就烫手,长期会把舵机或键帽压坏。

## 校准

### 第一步:悬空调方向

舵机臂悬空时:

| 串口输入 | 动作 |
|---|---|
| `p` + 回车 | 往「下压」方向转,持续到再发指令 |
| `r` + 回车 | 往「回位」方向转 |
| `a 10` + 回车 | 起点向下偏 10° |
| `a -10` + 回车 | 起点向上偏 10° |

`a` 的范围是 −60 ~ 60,不含 0。串口和联网动作共用一把锁,正在动作时发指令会提示 busy。

### 第二步:设两个角度

手机首页「调整舵机行程」:

- **下压角度**:从静止位置压到键帽需要的行程;
- **回位角度**:反向转回来松开键帽的行程。

两项都是 5°–180°,首次安装默认各 60°。

固件按舵机标称速度把角度换算成时长(**125 ms / 60°**),然后:

```
1600 µs 下压(时长按下压角度算)
   ↓
1500 µs 停转 3 秒     ← 停在这里,让按键被压下并保持一会儿
   ↓
1400 µs 反向回位(时长按回位角度算)
   ↓
1500 µs 停转,回执 done:<ts>
```

### 第三步:按实际结果调

连续旋转舵机**没有位置反馈**,固件不知道臂现在在哪。所以:

| 现象 | 怎么调 |
|---|---|
| 没按到,电脑没反应 | 增大下压角度 |
| 按到了,但松开后键还卡着 | 增大回位角度 |
| 回位过头,臂撞到外壳 | 减小回位角度 |
| 压得太狠,键帽下陷或机器异响 | 减小下压角度,或在臂端加泡棉缓冲 |
| 第一次准,后面越跑越偏 | 行程累计误差,见下 |

**每次只改一项,改完立刻实测一次。** 两个一起改,出了问题分不清是哪个方向的事。

### 重复性

同一组角度,两个方向的实际行程可能不完全相等(安装间隙、负载、供电电压都会影响)。
表现是「连按几次之后位置慢慢漂」。缓解办法:

- 回位角度略大于下压角度,让每次都有余量回到同一起点(靠机械限位或外壳挡住);
- 在臂的回位侧加一个机械挡块,让每次归位都撞到同一点;
- 供电稳一点,电压跌落会让转速变慢、同样时长走的行程变短。

目前**连续 10 轮的按压成功率还没有系统测过**,见 [`test-results.md`](test-results.md)。

## 供电与待机

固件把 Wi-Fi 设成 `WIFI_PS_MIN_MODEM`,长期待命时功耗较低,但仍建议:

- 用稳定的 5 V 电源,别用劣质充电头(电压不稳会导致反复重连);
- 断电重启后固件会自动重连并重新订阅,不需要人工干预;
- 如果放在需要长期通电的位置,注意舵机静止时也在耗电,以及外壳的散热。
