# Windows:让远程桌面在登录界面就上线(可选)

> 这一步和 ESP32 无关,是可选的。跳过也能用 —— 代价是冷启动后要等电脑有人登录,
> 远程桌面才连得进去。如果你找人在电脑前按一下也行,就不用做这个。

## 问题

电脑被舵机按下电源键后,Windows 冷启动会停在**登录界面**。此时:

- 系统服务已经在会话 0 里跑了;
- 但很多远控客户端是随**用户登录**启动的,所以「服务在跑」≠「登录前能连」。

结果是:机器确实开机了,远程桌面却连不上,你得等有人输密码。

在测试机上,普通**锁屏**状态(已经登录过、只是锁了)是可以远控的 —— 因为用户会话还在。
只有**冷启动停在登录界面**才有这个问题,容易误判成「远控坏了」。

## 做法

给远控启动器加一个 **SYSTEM 身份的开机计划任务**:开机 30 秒后以 SYSTEM 拉起启动器,
不限运行时长。SYSTEM 任务不依赖任何用户登录,所以登录界面还没出现时它已经在跑了。

本仓库提供了脚本 [`scripts/Setup-UURemotePreLogon.ps1`](../scripts/Setup-UURemotePreLogon.ps1),
以网易 UU 远程(`GameViewer`)为例。

### 脚本做了什么

1. 从注册表读 `HKLM\SYSTEM\CurrentControlSet\Services\GameViewerService` 的 `ImagePath`,
   解析出服务实际的 `GameViewerService.exe` 路径 —— 不写死安装目录,装在哪个盘都能用;
2. 确认同目录下有 `GameViewer.exe`(启动器,和常驻服务不是同一个文件);
3. 注册计划任务 `UU-Remote-System-Startup`:
   - 触发:At startup,延迟 `PT30S`;
   - 身份:`SYSTEM`,`LogonType ServiceAccount`;
   - 设置:不限运行时长(`PT0S`)、忽略新实例、电池供电也允许启动。

### 用法

**以管理员身份**打开 PowerShell,在仓库根目录:

```powershell
# 先干跑一遍,看清楚会往哪个 exe 上挂任务,不做任何修改
.\scripts\Setup-UURemotePreLogon.ps1 -WhatIf

# 确认无误再真正注册
.\scripts\Setup-UURemotePreLogon.ps1
```

脚本会先打印 `UU executable: <路径>`,再注册任务。它要求:

- 当前是管理员(否则直接报错退出,不会静默失败);
- UU 远程已经**正常安装并且能用**(服务存在);
- 以 `-WhatIf` 运行时不做管理员检查,可以安全地先看一眼。

### 验证

1. **重启**电脑(不是注销);
2. 停在登录界面**不要输入密码**;
3. 手机走蜂窝网络,用 UU 远程连这台机器。

连上了就说明生效。如果连不上,先确认机器真的起来了(电源指示灯、风扇、显示器有画面),
再在登录界面按 `Ctrl+Alt+Del` 看有没有反应 —— 先把「机器没启动」和「远控没起来」分开。

记录时把这几项分开写,别合成一个「成功/失败」:

| 项 | 怎么确认 |
|---|---|
| 机器已启动 | 电源指示灯、显示器出现登录界面 |
| 登录前已联网 | 路由器 DHCP 列表里能看到这台机器;或 ping 得通 |
| 远控已上线 | 手机端点连接能建立会话 |
| 真的没登录 | 屏幕上一直停在登录界面 |

### 还原

```powershell
.\scripts\Setup-UURemotePreLogon.ps1 -Remove
```

会先停掉正在运行的任务,再 `Unregister-ScheduledTask`。脚本本身**不改注册表、不改服务配置**,
所以删掉任务就等于完全还原,不会留下残留。

## 注意事项

- **这是 SYSTEM 权限的开机自启任务。** SYSTEM 比管理员权限还高,任何能改这个任务的人
  都能以 SYSTEM 身份执行任意程序。只在你自己控制的机器上做,做完确认任务的动作和路径是对的。
- 换远控软件时,把脚本里的 `GameViewerService` / `GameViewer.exe` 换成对应服务的名字。
  但**别改成通过 `cmd /c` 或 `powershell -Command` 转一层的写法** —— 多一层解释器就多一个
  被改写的入口。
- 部分远控软件自身有「开机自启 / 登录前启动」的选项,优先用它官方的。官方支持就不用这个脚本。
- Windows 11 和 Windows 10 的行为**不完全一样**。本项目只在**一台 Win10 机器**上验证过登录前可连接,
  Win11 需要你自己逐台验证。
- 有些企业策略会禁用 SYSTEM 计划任务或限制服务交互,那就换思路(比如把远控注册成服务)。
